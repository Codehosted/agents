## Product acceptance notes

- Open-source-friendly local CLI/library for turning static page output/user stories into a flow diagram and Playwright script.
- Generated flow includes page URLs, button/link IDs/selectors, actions, assertions, and screenshots.
- Separate screen recorder process can capture automation playback to video.
- Supports narration/script text so a user can describe what to do and watch playback afterward.
- Prefer faster static output parsing for planning, then Playwright only for execution/recording.
- Does not require proprietary analytics tools; Mixpanel-like event timeline/report is generated locally.
